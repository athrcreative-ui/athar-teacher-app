# صور محتوى الدروس

هذا المجلد مخصص لصور الدروس ولقطات الشاشة المستخدمة داخل التطبيق.

- الصيغة المعتمدة للصور الجديدة: `webp`.
- استخدم أسماء ملفات قصيرة وواضحة بالإنجليزية أو بالأرقام والشرطات.
- بعد رفع الصورة هنا، يكون مسار استخدامها داخل بيانات التطبيق بالشكل:
  `/assets/lesson-images/file-name.webp`

مثال:
`/assets/lesson-images/lesson-01-cover.webp`
